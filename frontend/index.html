FAQ

Common questions

Do I need to install anything?
+
No. FigmaForge is fully web-based. You paste your Figma URL, configure your options, and download a zip. The only thing you need is a free Figma Personal Access Token, which takes 30 seconds to create.
How do I get a Figma token?
+
Go to figma.com → click your profile icon → Settings → Personal Access Tokens → Generate new token. It's free and takes about 30 seconds. Your token is never stored on our servers — it's used only at generation time.
What does the generated code look like?
+
Each Figma frame becomes a separate component file. Colors, spacing, border-radius, typography, and layout direction are mapped to Tailwind classes. The output is a complete runnable project — not a snippet — with package.json, config files, and a README included.
What if I pick incompatible versions?
+
FigmaForge's version compatibility engine automatically detects conflicts before generating. For example, if you choose Next.js 12 with Tailwind 4, it warns you and offers to auto-correct to a compatible combination. No broken installs.
Is the code production-ready?
+
It's a strong starting point. Generated components are clean functional components with semantic HTML, Tailwind classes, and proper structure. For best results, use the AI optimizer (Pro plan) which refactors for accessibility, responsiveness, and reusability.
Can I cancel my subscription anytime?
+
Yes. Cancel anytime from your dashboard. You keep access until the end of your billing period. No questions asked.
