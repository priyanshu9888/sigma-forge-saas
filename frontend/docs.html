Build production code directly from Figma

Everything you need to go from design URL to deployable code. This guide is optimized for the demo frontend and the FastAPI backend.

1. Connect Figma

Paste a Figma file URL or key and add your Personal Access Token.

2. Choose a framework

Pick Next.js, React, Vue, Flutter, or SwiftUI with version-safe defaults.

3. Generate & download

Generate code and grab your zip. Demo mode uses mock output if the API is offline.

API Endpoints

POST /generate Run a generation job
GET /download/{project_id} Download the zip
GET /me Current user + usage
POST /checkout Stripe subscription session
POST /stripe/webhook Plan updates

Sample Request

curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "figma_url": "https://figma.com/file/abc123/MyDesign",
    "framework": "nextjs",
    "version": "14",
    "styling": "tailwind",
    "tailwind_version": "3",
    "package_manager": "pnpm",
    "figma_token": "fig_xxxxx"
  }'
